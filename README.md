# 유령 쫓기 게임

> 혼자 있고 싶은 밤, 옥상 정원에 유령들이 찾아온다.

**지금 바로 플레이:** https://higogo1.github.io/ghost-rooftop/

설치 없이 브라우저에서 바로 즐기는 웹 미니게임입니다. PC에서는 키보드로, 휴대폰에서는 화면의 터치 버튼으로 플레이할 수 있습니다.

## 어떤 게임인가요?

캄캄한 밤, 주인공은 혼자 있고 싶어서 옥상 정원에 올라왔습니다. 그런데 사방에서 유령들이 하나둘 나타나 다가옵니다.
돌을 던져 유령을 쫓아내고, 아슬아슬하게 피하면서 조용한 밤을 지켜 내세요.

- 주변은 어둡고, 주인공 주변과 전구, 랜턴 근처만 밝습니다.
- 유령은 화면 밖 아무 방향에서 나타나 주인공을 따라옵니다.
- 스테이지가 올라갈수록 유령이 많아지고 빨라집니다.

## 조작법

| 키 | 동작 |
| --- | --- |
| `←` `↑` `↓` `→` | 이동 |
| `Space` 또는 `Z` | 바라보는 방향으로 돌 던지기 |
| `P` / `Esc` | 일시정지 |
| `M` | 소리 켜기 / 끄기 |
| `Enter` | 게임 시작 / 다시 하기 |

화면 오른쪽 아래에 지금 누르고 있는 키가, 왼쪽 위에 던질 수 있는 돌 개수가 표시됩니다.

## 게임 규칙

- **돌 던지기:** 평소에는 돌을 무한으로 던질 수 있습니다. 맞은 유령은 달아납니다.
- **피하기:** 유령이 스치듯 지나가게 피하면 그 유령도 물리친 것으로 카운트됩니다.
- **스테이지 클리어:** 목표 수만큼 유령을 물리치면 다음 스테이지로 넘어갑니다.
- **생명:** 생명 3개로 시작합니다. 유령에게 닿으면 하나 줄고, 3스테이지마다 하나 회복합니다.

### 돌발상황

스테이지 중간에 돌발상황이 터집니다. 5초 전부터 카운트다운이 나오니 미리 대비하세요.

- 유령 떼가 사방에서 직선으로 돌진합니다.
- 던질 수 있는 돌은 **크고 반짝이는 빛나는 돌 단 1개**뿐입니다.
- 빛나는 돌은 멈추지 않고 날아가며, **던진 방향에 있는 유령을 모두** 쫓아냅니다.
- 돌을 쓴 뒤에는 방향키로 피하면서 끝까지 버텨야 합니다.

## 점수

| 상황 | 점수 |
| --- | --- |
| 아슬아슬하게 피하기 | 25점 × 스테이지 보너스 × 연속 콤보 (최대 5배) |
| 돌로 유령 쫓아내기 | 20점 |
| 돌진 유령이 화면 밖으로 지나감 | 10점 |
| 돌발상황 버텨내기 | 200점 + 스테이지 × 100점 |
| 스테이지 클리어 | 스테이지 × 100점 |

피할수록 점수가 크게 오릅니다. 최고 기록은 브라우저에 저장됩니다.

## 내 컴퓨터에서 실행하기

`index.html` 파일 하나로 되어 있어서 별도 설치가 필요 없습니다.

```bash
git clone https://github.com/higogo1/ghost-rooftop.git
cd ghost-rooftop
# index.html을 더블클릭하거나, 간이 서버로 열기
python -m http.server 8000   # 브라우저에서 http://localhost:8000
```

## 기술

HTML, CSS, JavaScript(Canvas)만 사용했습니다. 외부 라이브러리는 없습니다.
